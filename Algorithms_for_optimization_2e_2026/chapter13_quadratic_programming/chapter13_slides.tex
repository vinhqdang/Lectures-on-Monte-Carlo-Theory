\section{13.1 Problem Formulation}
% =========================================================================

\begin{frame}[allowframebreaks]{What Is a Quadratic Program?}

  A \textbf{quadratic program} (QP) is an optimization problem in which the
  \emph{objective function is quadratic} (it contains squared or cross-product
  terms in the decision variables) and all \emph{constraints are linear}.
  Quadratic programs arise whenever you fit a model to data, control a physical
  system with energy costs, or solve a step of Newton's method inside a
  constrained setting.

  \begin{block}{Quadratic Program --- General Form (Eq.~13.1)}
    \[
      \minimize_{\bx}\quad \frac{1}{2}\bx^{\top}\bQ\bx + \bq^{\top}\bx
      \quad\text{subject to}\quad
      \bC_{\text{LE}}\bx \leq \bd_{\text{LE}},\quad
      \bC_{\text{EQ}}\bx = \bd_{\text{EQ}}
    \]
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\bx \in \R^n$ & the \textbf{decision vector} (what we optimise over); $n$ is the number of variables\\
      $\bQ \in \R^{n\times n}$ & the \textbf{cost matrix} (symmetric); it encodes how pairs of variables interact\\
      $\bq \in \R^n$ & the \textbf{linear cost vector}; it shifts the minimum away from the origin\\
      $\bC_{\text{LE}} \in \R^{p\times n},\; \bd_{\text{LE}} \in \R^p$ & define $p$ \textbf{inequality} constraints $\bC_{\text{LE}}\bx \leq \bd_{\text{LE}}$\\
      $\bC_{\text{EQ}} \in \R^{c\times n},\; \bd_{\text{EQ}} \in \R^c$ & define $c$ \textbf{equality} constraints $\bC_{\text{EQ}}\bx = \bd_{\text{EQ}}$\\
      $\top$ & the \textbf{transpose} operator (flips a column vector into a row vector)\\
    \end{tabular}
  \end{block}

  \begin{alertblock}{How to Read the Objective}
    The term $\tfrac{1}{2}\bx^{\top}\bQ\bx$ is a \emph{bowl-shaped} (or saddle-shaped)
    surface in $n$ dimensions.  When $\bQ$ is \textbf{positive definite} (all eigenvalues
    strictly positive) the bowl opens upward and has a unique lowest point.
    The term $\bq^{\top}\bx$ is a tilted plane that shifts that lowest point.
    Together they form an \emph{elliptic paraboloid}: the contour lines are ellipses
    centred at the unconstrained minimiser $\bx^* = -\bQ^{-1}\bq$.
  \end{alertblock}

  \framebreak

  \textbf{Why the factor of $\tfrac{1}{2}$?}  Taking the gradient of
  $\tfrac{1}{2}\bx^{\top}\bQ\bx + \bq^{\top}\bx$ gives $\bQ\bx + \bq$, which is
  clean and matches Newton's method.  Without the $\tfrac{1}{2}$ the gradient would
  carry an extra factor of $2$.

  \textbf{Expanding the quadratic term.}  Each entry of $\bQ$ contributes to the
  objective as follows.  The diagonal entry $Q_{ii}$ contributes
  $\tfrac{1}{2}Q_{ii}x_i^2$ (a pure squared term), while the off-diagonal entries
  $Q_{ij}$ and $Q_{ji}$ together contribute
  $\tfrac{1}{2}(Q_{ij}+Q_{ji})x_ix_j$ (a cross-product term coupling variable $i$ to
  variable $j$).  Since $\bQ$ is symmetric, $Q_{ij} = Q_{ji}$, so the coupling
  coefficient simplifies to $Q_{ij}x_ix_j$.

  \textbf{Connection to Newton's method.}  The second-order Taylor expansion of any
  smooth function $f$ around a reference point $\bx_{\text{ref}}$ is
  \[
    f(\bx) \approx f(\bx_{\text{ref}})
      + \nabla f(\bx_{\text{ref}})^{\top}(\bx - \bx_{\text{ref}})
      + \tfrac{1}{2}(\bx-\bx_{\text{ref}})^{\top}\nabla^2 f(\bx_{\text{ref}})(\bx-\bx_{\text{ref}})
  \]
  where $\nabla$ (nabla, the gradient/del operator) denotes the vector of partial
  derivatives and $\nabla^2$ (nabla-squared) denotes the matrix of second derivatives
  (the Hessian).  If we drop the constant term and write $\bx' = \bx - \bx_{\text{ref}}$,
  this matches the QP objective with $\bQ = \nabla^2 f(\bx_{\text{ref}})$ and
  $\bq = \nabla f(\bx_{\text{ref}})$.  In other words, \emph{a single Newton step
  subject to linear constraints is exactly a quadratic program}.

  \begin{alertblock}{Key Takeaway}
    Quadratic programs are the natural model whenever costs are quadratic and
    constraints are linear.  They include unconstrained quadratics, constrained
    least-squares problems, and Newton sub-problems as special cases.
  \end{alertblock}

\end{frame}

\begin{frame}[allowframebreaks]{Convex QP and Its Equivalent Least-Squares Form}

  When the cost matrix $\bQ$ is \textbf{positive definite} (meaning all eigenvalues
  $\lambda$ (lambda) are strictly positive, so the objective bowl has no flat or
  downward directions), the QP is called \emph{convex}.  Convex QPs are particularly
  attractive because every local minimum is also a global minimum.

  \textbf{Cholesky factorisation.}  Every positive-definite matrix $\bQ$ can be
  written as $\bQ = \bU^{\top}\bU$, where $\bU$ is an upper-triangular matrix with
  positive diagonal entries.  This is called the \textbf{Cholesky} (pronounced
  \emph{kol-ESS-kee}) decomposition.

  \begin{block}{Conversion to Least-Squares (Eq.~13.2)}
    Substituting $\bQ = \bU^{\top}\bU$ and completing the square, the convex QP becomes
    the constrained \emph{least-squares problem}:
    \[
      \minimize_{\bx}\; \norm{\bA\bx - \bb}
      \quad\text{subject to}\quad
      \bC_{\text{LE}}\bx \leq \bd_{\text{LE}},\;
      \bC_{\text{EQ}}\bx = \bd_{\text{EQ}}
    \]
    with the substitutions $\bA = \bU$ and $\bb = -\bU^{-\top}\bq$.
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\norm{\cdot}$ & the Euclidean (L2) norm: $\norm{\mathbf{v}} = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$\\
      $\bA = \bU$ & the upper-triangular Cholesky factor of $\bQ$\\
      $\bb = -\bU^{-\top}\bq$ & the right-hand-side vector after substitution\\
      $\bU^{-\top}$ & the inverse of $\bU^{\top}$ (equivalently, the transpose of $\bU^{-1}$)\\
    \end{tabular}
  \end{block}

  \framebreak

  \textbf{Why is this useful?}  Least-squares problems are extremely well-studied;
  fast and numerically stable solvers exist (SVD, QR, normal equations).  The
  conversion tells us that solving a convex QP is no harder than solving a
  constrained least-squares problem.

  \begin{columns}[T]
    \column{0.50\textwidth}
      \textbf{Transformation chain} (Figure 13.1):
      \begin{center}
        \includegraphics[width=\linewidth]{fig_transform_chain}
      \end{center}
      The figure shows how a general QP passes through a sequence of
      reductions until it becomes a nonnegative least-squares problem
      that can be solved with a simple active-set algorithm.

    \column{0.46\textwidth}
      \textbf{Geometric observations:}\\[0.4em]
      The \emph{feasible set} (the set of all $\bx$ that satisfy the constraints)
      is a convex polytope --- the intersection of half-spaces and hyperplanes,
      exactly as in linear programming.  However, unlike linear programming,
      the optimal solution of a QP need \emph{not} lie at a vertex of the
      feasible set.  It may lie on the interior, on an edge or face, at a vertex,
      or the problem may be infeasible or unbounded depending on the data.
  \end{columns}

\end{frame}

\begin{frame}[allowframebreaks]{Example 13.1 --- QP with Elliptical Contours}

  This example illustrates how the optimal solution of a QP can lie on the
  \emph{boundary} of the feasible set at a point that is not a vertex.  The
  objective contours are ellipses whose centre (the unconstrained minimum)
  falls outside the feasible region, so the solution is pushed to the nearest
  feasible point on the boundary.

  \begin{columns}[T]
    \column{0.50\textwidth}
      \begin{block}{Problem Statement}
        \[
          \minimize_{x_1,\,x_2}
          \left\|\begin{bmatrix}2&1\\-4&3\end{bmatrix}
          \begin{bmatrix}x_1\\x_2\end{bmatrix}
          - \begin{bmatrix}1\\2\end{bmatrix}\right\|
        \]
        \[
          \text{subject to}\quad
          2x_1 - x_2 \geq 2,\quad
          x_1 - 3x_2 \leq 4
        \]
      \end{block}

      \begin{block}{Notation}
        The objective $\|\bA\bx - \bb\|$ measures how far $\bA\bx$ is from the
        target vector $\bb = [1,\,2]^{\top}$.  Here $\bA$ is the $2\times 2$ matrix
        shown, $x_1$ and $x_2$ are the two decision variables, and $\|\cdot\|$ is the
        Euclidean length of the residual vector $\bA\bx - \bb$.
      \end{block}

    \column{0.46\textwidth}
      \begin{center}
        \includegraphics[width=\linewidth]{fig_qp_example}
      \end{center}
  \end{columns}

  \framebreak

  \textbf{Reading the constraints.}  The first constraint $2x_1 - x_2 \geq 2$ defines
  a half-plane: all points at or above the line $2x_1 - x_2 = 2$.  The second
  constraint $x_1 - 3x_2 \leq 4$ defines another half-plane.  The feasible set is the
  intersection of these two half-planes.

  \textbf{Solution.}  The unconstrained minimiser of $\|\bA\bx - \bb\|$ is
  $\bx^{\mathrm{unc}} = (\bA^{\top}\bA)^{-1}\bA^{\top}\bb$, which lies outside the
  feasible set.  The QP solver finds the closest feasible point, which turns out to
  be $\bx^* = [1.4,\; 0.8]^{\top}$.  This point lies on the boundary of the first
  constraint (the line $2x_1 - x_2 = 2$), but not at a vertex.

  \begin{alertblock}{Key Insight}
    A QP solution can lie anywhere in or on the feasible set --- interior, face, edge,
    or vertex --- depending on where the objective ellipses are centred relative to the
    constraints.  This flexibility is what makes QP more expressive than LP.
  \end{alertblock}

\end{frame}

\begin{frame}[allowframebreaks]{Four Solution Cases for a QP}

  The relationship between the objective function and the feasible set can
  produce four qualitatively different outcomes.  Understanding these cases
  helps diagnose why a QP might fail to solve.

  \begin{center}
    \includegraphics[width=0.82\linewidth]{fig_qp_cases}
  \end{center}

  \textbf{Case 1 --- Internal solution.}  The unconstrained minimiser of the
  objective lies \emph{inside} the feasible set.  In this case the constraints
  are inactive and the QP solution equals the unconstrained solution.

  \textbf{Case 2 --- Boundary solution.}  The unconstrained minimiser lies
  \emph{outside} the feasible set.  The solution is the closest feasible point
  to the unconstrained minimiser, and it lies on one or more active constraint
  boundaries.  This is the most common case in practice.

  \textbf{Case 3 --- Infeasible.}  The feasible set is empty --- the constraints
  contradict each other so there is no $\bx$ satisfying all of them simultaneously.
  For example, requiring $x_1 \geq 5$ and $x_1 \leq 3$ at the same time.

  \textbf{Case 4 --- Unbounded.}  If $\bQ$ is not positive definite (it has a zero
  or negative eigenvalue $\lambda$ (lambda)), the objective has a direction along which
  it decreases without bound, so the minimum is $-\infty$.

  \begin{alertblock}{Key Takeaway}
    Always check that $\bQ$ is positive definite (or at least positive semidefinite)
    and that the constraint system is feasible before invoking a QP solver.
  \end{alertblock}

\end{frame}

\section{13.2 Unconstrained Least-Squares Problems}
% =========================================================================

\begin{frame}[allowframebreaks]{Unconstrained Least Squares: Problem and Cases}

  The simplest special case of a convex QP is the \textbf{unconstrained
  least-squares problem}: find the vector $\bx$ that makes $\bA\bx$ as close as
  possible to $\bb$, with no constraints on $\bx$.  This arises in linear
  regression, signal processing, and as a building block for the constrained
  problems we tackle in the rest of the chapter.

  \begin{block}{Unconstrained Least-Squares Problem (Eq.~13.3)}
    \[
      \minimize_{\bx}\; \norm{\bA\bx - \bb},
      \qquad \bA \in \R^{m\times n},\;\; \bx \in \R^n,\;\; \bb \in \R^m
    \]
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\bA \in \R^{m\times n}$ & the \textbf{measurement matrix} with $m$ rows (observations) and $n$ columns (variables)\\
      $\bx \in \R^n$ & the \textbf{unknown vector} we are solving for\\
      $\bb \in \R^m$ & the \textbf{target vector} (observed data or desired output)\\
      $\norm{\bA\bx - \bb}$ & the \textbf{residual norm} --- the Euclidean distance between $\bA\bx$ and $\bb$\\
    \end{tabular}
  \end{block}

  \framebreak

  \textbf{Case 1: $\bA$ is square and invertible.}  When $m = n$ and $\bA$ has
  full rank, the system $\bA\bx = \bb$ has a unique exact solution.  Setting
  $\bA\bx = \bb$ and solving:
  \[
    \bx^* = \bA^{-1}\bb \quad\text{(Eq.~13.4)}
  \]
  The residual $\norm{\bA\bx^* - \bb} = 0$; the fit is perfect.

  \textbf{Case 2: $\bA$ is not invertible (rank-deficient or rectangular).}
  When $m > n$ (more equations than unknowns, i.e., overdetermined), there may be
  no exact solution.  When $m < n$ (more unknowns than equations, i.e.,
  underdetermined), there are infinitely many exact solutions.  In both cases we
  use the \textbf{Singular Value Decomposition} (SVD) to find the
  \emph{minimum-norm least-squares solution}.

  \begin{block}{Singular Value Decomposition (Eq.~13.5)}
    Any matrix $\bA \in \R^{m\times n}$ of rank $k$ can be written as:
    \[
      \bA = \bU\begin{bmatrix}\bT & \mathbf{0}\\\mathbf{0}&\mathbf{0}\end{bmatrix}\bV^{\top}
    \]
    where $\bU \in \R^{m\times m}$ and $\bV \in \R^{n\times n}$ are
    \textbf{orthogonal matrices} (their columns are mutually perpendicular unit
    vectors), and $\bT \in \R^{k\times k}$ is \textbf{diagonal} with positive entries
    called the \emph{singular values}.
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\bU$ & the \textbf{left singular vectors} (output directions)\\
      $\bV$ & the \textbf{right singular vectors} (input directions)\\
      $\bT$ & diagonal matrix of \textbf{singular values} $\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_k > 0$\\
              & (sigma values measure how much $\bA$ stretches each direction)\\
      $k$   & the \textbf{rank} of $\bA$ (number of linearly independent rows or columns)\\
    \end{tabular}
  \end{block}

  \framebreak

  \textbf{Minimum-norm solution via the pseudoinverse.}  The SVD gives us the
  \textbf{Moore--Penrose pseudoinverse} $\bA^+$, which generalises $\bA^{-1}$ to
  non-square and rank-deficient matrices.

  \begin{block}{Pseudoinverse and Minimum-Norm Solution (Eqs.~13.18--13.19)}
    \[
      \bx^* = \bA^+\bb,
      \qquad\text{where}\qquad
      \bA^+ = \bV\begin{bmatrix}\bT^{-1}&\mathbf{0}\\\mathbf{0}&\mathbf{0}\end{bmatrix}\bU^{\top}
    \]
    This gives the unique solution with the \textbf{smallest Euclidean norm}
    $\norm{\bx^*}$ among all vectors that minimise $\norm{\bA\bx - \bb}$.
  \end{block}

  \textbf{Special forms of the pseudoinverse:}

  \begin{tabular}{lll}
    $\bA^+ = (\bA^{\top}\bA)^{-1}\bA^{\top}$ & when columns of $\bA$ are linearly independent & (Eq.~13.20)\\
    $\bA^+ = \bA^{\top}(\bA\bA^{\top})^{-1}$ & when rows of $\bA$ are linearly independent & (Eq.~13.21)\\
    $\bA^+ = \bA^{-1}$ & when $\bA$ is square and invertible & (Eq.~13.22)\\
  \end{tabular}

  \begin{alertblock}{How to Read This}
    The formula $\bA^+ = (\bA^{\top}\bA)^{-1}\bA^{\top}$ is the well-known
    \emph{normal equations} solution in statistics.  It says: project $\bb$ onto the
    column space of $\bA$ by pre-multiplying by $\bA^{\top}$ (this forms the normal
    equations $\bA^{\top}\bA\bx = \bA^{\top}\bb$) and then solve for $\bx$.
  \end{alertblock}

\end{frame}

\begin{frame}[allowframebreaks]{SVD Derivation of the Pseudoinverse}

  This section shows step-by-step how substituting the SVD into the least-squares
  objective leads naturally to the pseudoinverse formula.  Following the algebra
  reveals \emph{why} the pseudoinverse is the right object to use.

  \textbf{Step 1: Substitute SVD into the objective.}

  \begin{align}
    \norm{\bA\bx - \bb}^2
    &= \left\|\bU\begin{bmatrix}\bT&\mathbf{0}\\\mathbf{0}&\mathbf{0}\end{bmatrix}
       \bV^{\top}\bx - \bb\right\|^2 \tag{13.6}
  \end{align}

  \textbf{Step 2: Use the fact that multiplying by an orthogonal matrix
  $\bU$ does not change the Euclidean norm} (because $\bU^{\top}\bU = \mathbf{I}$,
  so $\|\bU\mathbf{v}\| = \|\mathbf{v}\|$).  Pre-multiplying by $\bU^{\top}$:

  \begin{align}
    &= \left\|\begin{bmatrix}\bT&\mathbf{0}\\\mathbf{0}&\mathbf{0}\end{bmatrix}
       (\bV^{\top}\bx) - (\bU^{\top}\bb)\right\|^2 \tag{13.8}
  \end{align}

  \textbf{Step 3: Partition.}  Write $\bU = [\bU_1,\, \bU_2]$ where $\bU_1$ holds
  the first $k$ columns (corresponding to nonzero singular values) and $\bU_2$ holds
  the remaining columns.  Similarly write $\bV = [\bV_1,\, \bV_2]$.  Define
  $\mathbf{v}_{\text{fixed}} = \bV_1^{\top}\bx$ (the $k$ components of $\bx$
  that affect the objective) and $\mathbf{v}_{\text{free}} = \bV_2^{\top}\bx$
  (the remaining components that do \emph{not} affect the objective value).

  The squared norm splits into two independent pieces:
  \begin{align}
    &= \norm{\bT\mathbf{v}_{\text{fixed}} - \bU_1^{\top}\bb}^2
       + \norm{\bU_2^{\top}\bb}^2 \tag{13.11}
  \end{align}

  \framebreak

  \textbf{Step 4: Minimise each piece.}  The second term $\norm{\bU_2^{\top}\bb}^2$
  does not depend on $\bx$ at all --- it is a constant that cannot be reduced.
  The first term is minimised by choosing:

  \begin{block}{Optimal Fixed Component (Eq.~13.13)}
    \[
      \mathbf{v}^*_{\text{fixed}} = \bT^{-1}\bU_1^{\top}\bb
    \]
    Because $\bT$ is diagonal with positive entries, $\bT^{-1}$ simply inverts each
    diagonal entry: $(\bT^{-1})_{ii} = 1/\sigma_i$ (sigma sub i, the $i$-th singular value).
  \end{block}

  \textbf{Step 5: Minimum-norm choice for the free component.}  Since
  $\mathbf{v}_{\text{free}}$ does not appear in the objective, any value gives the
  same residual.  To get the solution with the smallest $\norm{\bx}$, we set
  $\mathbf{v}^*_{\text{free}} = \mathbf{0}$.

  \textbf{Step 6: Back-substitute} to get $\bx^*$:
  \[
    \bx^* = \bV\begin{bmatrix}\mathbf{v}^*_{\text{fixed}}\\\mathbf{0}\end{bmatrix}
    = \bV\begin{bmatrix}\bT^{-1}&\mathbf{0}\\\mathbf{0}&\mathbf{0}\end{bmatrix}\bU^{\top}\bb
    = \bA^+\bb
  \]

  \begin{alertblock}{Key Insight}
    The pseudoinverse $\bA^+$ inverts the effect of $\bA$ on directions where $\bA$
    is nonzero (the first $k$ singular directions), and sets the solution to zero on
    directions where $\bA$ has no effect.  This is exactly the minimum-norm choice.
  \end{alertblock}

\end{frame}

\begin{frame}[fragile]{Python: Pseudoinverse and Least Squares}
\begin{lstlisting}[caption={Unconstrained least-squares via pseudoinverse (NumPy/SciPy)}]
import numpy as np
from scipy.linalg import lstsq, svd

# Example: A is 3x2 (overdetermined), b is 3-vector
A = np.array([[2., 1.],
              [-4., 3.],
              [1., 1.]])
b = np.array([1., 2., 0.5])

# --- Method 1: pseudoinverse via SVD ---
A_pinv = np.linalg.pinv(A)      # V T^{-1} U^T (eq. 13.19)
x_star = A_pinv @ b
print(f"x* (pinv): {x_star}")   # minimum-norm least-squares solution

# --- Method 2: scipy lstsq (numerically robust, recommended) ---
x_lstsq, residuals, rank, sv = lstsq(A, b)
print(f"x* (lstsq): {x_lstsq}")

# --- Method 3: normal equations (columns linearly independent) ---
x_normal = np.linalg.solve(A.T @ A, A.T @ b)  # eq. (13.20)
print(f"x* (normal eq): {x_normal}")

# Verify residual
print(f"||Ax - b|| = {np.linalg.norm(A @ x_star - b):.6f}")
\end{lstlisting}
\end{frame}

\section{13.3 Least Squares with Linear Inequalities}
% =========================================================================

\begin{frame}[allowframebreaks]{Least Squares with Linear Inequalities}

  We now add linear inequality constraints to the least-squares problem.
  This is the case that arises most often in practice: we want to minimise
  a quadratic residual while ensuring that $\bx$ satisfies a set of one-sided
  bounds or more general linear restrictions.

  \begin{block}{Problem Statement (Eq.~13.23)}
    \[
      \minimize_{\bx}\; \norm{\bA\bx - \bb}
      \qquad \text{subject to}\quad \bC\bx \geq \bd
    \]
    where $\bC \in \R^{q\times n}$ and $\bd \in \R^q$ define $q$ inequality constraints.
    (Less-than inequalities $\bC'\bx \leq \bd'$ are negated to $(-\bC')\bx \geq (-\bd')$.
    Equality constraints are handled separately by elimination, described below.)
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\bC \in \R^{q\times n}$ & the \textbf{constraint matrix}, one row per constraint\\
      $\bd \in \R^q$           & the \textbf{right-hand-side} vector of constraint bounds\\
      $\geq$ applied to vectors & means \emph{component-wise}: $(\bC\bx)_i \geq d_i$ for every $i$\\
    \end{tabular}
  \end{block}

  \framebreak

  \textbf{Handling equality constraints by elimination.}  If the problem also
  includes equality constraints $\bC_{\text{EQ}}\bx = \bd_{\text{EQ}}$, we can
  \emph{eliminate} them by changing variables.  The key tool is the
  \textbf{LQ decomposition}: we write $\bC_{\text{EQ}} = \mathbf{L}\mathbf{Q}$
  where $\mathbf{L}$ is lower-triangular and $\mathbf{Q}$ is orthogonal.  This is
  just the QR decomposition applied to the transpose of $\bC_{\text{EQ}}$.

  \textbf{Substitution.}  Because $\mathbf{Q}$ is orthogonal, the change of
  variables $\bx = \mathbf{Q}^{\top}\mathbf{y}$ (where $\mathbf{y}$ is a new
  vector of the same length) does not change the Euclidean norms.  Partitioning
  $\mathbf{y} = [\mathbf{y}_1;\, \mathbf{y}_2]$ where $\mathbf{y}_1 \in \R^c$
  (with $c$ the number of equality constraints) and
  $\mathbf{y}_2 \in \R^{n-c}$, the equality constraint pins
  $\mathbf{y}_1^* = \mathbf{L}_{11}^{-1}\bd_{\text{EQ}}$ (Eq.~13.24) and
  the optimisation reduces to the smaller variable $\mathbf{y}_2$.

  \begin{block}{Reduced Problem after Equality Elimination (Eq.~13.26)}
    \[
      \minimize_{\mathbf{y}_2}\;
      \left\|(\bA\mathbf{Q}^{\top})_{(\cdot,c+1:n)}\mathbf{y}_2
      - \left(\bb - (\bA\mathbf{Q}^{\top})_{(\cdot,1:c)}\mathbf{y}_1^*\right)\right\|
    \]
    \[
      \text{s.t.}\quad
      (\bC\mathbf{Q}^{\top})_{(\cdot,c+1:n)}\mathbf{y}_2
      \geq \bd - (\bC\mathbf{Q}^{\top})_{(\cdot,1:c)}\mathbf{y}_1^*
    \]
    where the subscript $(\cdot,c+1:n)$ means ``all rows, columns $c{+}1$ through $n$''.
  \end{block}

  \begin{alertblock}{How to Read This}
    The reduced problem has the same structure as the original (least squares with
    inequalities) but with $n - c$ variables instead of $n$.  Each equality
    constraint we eliminate reduces the problem dimension by one, making the
    remaining optimisation cheaper.  Once we solve for $\mathbf{y}_2^*$, we
    back-substitute to recover $\bx^* = \mathbf{Q}^{\top}[\mathbf{y}_1^*;\,\mathbf{y}_2^*]$.
  \end{alertblock}

\end{frame}

\begin{frame}[allowframebreaks]{Algorithm 13.1 --- Solve Quadratic Program (General Form)}

  Algorithm 13.1 is the top-level procedure for solving a general convex QP.
  It orchestrates the sequence of reductions: from QP to least-squares with
  inequalities, then uses the lower-level solver described in the next sections.

  \begin{alertblock}{What Problem This Solves}
    Given a convex QP with quadratic objective, inequality constraints, and
    (optionally) equality constraints, Algorithm 13.1 converts it step by step
    into a form that the NNLS solver (Algorithm 13.4) can handle.
  \end{alertblock}

  \textbf{Step 1.}  Extract the problem data: matrices $\bA$, $\bb$ (from the
  Cholesky factorisation of $\bQ$), $\bC_{\text{LE}}$, $\bd_{\text{LE}}$,
  $\bC_{\text{EQ}}$, $\bd_{\text{EQ}}$.

  \textbf{Step 2.}  Compute the LQ decomposition of $\bC_{\text{EQ}}$:
  $\bC_{\text{EQ}} = \mathbf{L}\mathbf{Q}$, where $\mathbf{L}$ is
  lower-triangular and $\mathbf{Q}$ is orthogonal.  This step costs
  $O(cn^2)$ operations where $c$ is the number of equality constraints and
  $n$ is the number of variables.

  \textbf{Step 3.}  Compute $\mathbf{y}_1^* = \mathbf{L}_{11}^{-1}\bd_{\text{EQ}}$
  by forward substitution (cheap because $\mathbf{L}_{11}$ is triangular).

  \textbf{Step 4.}  Form the reduced matrices $\bA_2 = (\bA\mathbf{Q}^{\top})_{(\cdot,c+1:n)}$,
  $\bb_2 = \bb - (\bA\mathbf{Q}^{\top})_{(\cdot,1:c)}\mathbf{y}_1^*$, and the
  corresponding reduced constraint matrices.

  \textbf{Step 5.}  Call the Least-Squares-with-Inequalities solver on the reduced
  $(n-c)$-dimensional problem.  The total cost is dominated by this inner solve.

  \textbf{Step 6.}  Recover the original solution by back-substitution:
  $\bx^* = \mathbf{Q}^{\top}[\mathbf{y}_1^*;\, \mathbf{y}_2^*]$.

  \begin{exampleblock}{Worked Complexity Note}
    If the original problem has $n = 10$ variables and $c = 3$ equality constraints,
    the reduced problem has only $10 - 3 = 7$ variables.  If additionally there are
    $q = 5$ inequality constraints, the inner NNLS problem has a matrix of size
    roughly $7 \times 5$.  Eliminating equalities significantly speeds up the solve.
  \end{exampleblock}

  \begin{block}{Key Assumption}
    The equality constraint matrix $\bC_{\text{EQ}} \in \R^{c\times n}$ must have
    full row rank $c$ (with $c < n$).  This means no two equality constraints are
    redundant (parallel hyperplanes) or contradictory.  If this fails, the problem
    is either infeasible or under-specified.
  \end{block}

\end{frame}

\begin{frame}[allowframebreaks]{Example 13.2 --- 3D QP with Equality Constraint}

  This example demonstrates Algorithm 13.1 on a three-dimensional problem with
  both inequality and equality constraints.  After eliminating the equality
  constraint, the problem reduces to two dimensions, which is much easier to solve.

  \begin{columns}[T]
    \column{0.50\textwidth}
      \begin{block}{Original 3D Problem}
        \small
        \[
          \minimize_{\bx}
          \left\|\begin{bmatrix}1&2&3\\-2&0&0\end{bmatrix}\bx
          - \begin{bmatrix}1\\2\end{bmatrix}\right\|
        \]
        \[
          \bx \leq \begin{bmatrix}1\\1\\1\end{bmatrix}\!,\quad
          \bx \geq \mathbf{0},\quad
          [-1\;\; 1\;\; 1]\bx = 0
        \]
      \end{block}

      \textbf{Reading the constraints.}  The vector inequality $\bx \leq [1,1,1]^{\top}$
      means each component is at most 1: $x_1 \leq 1$, $x_2 \leq 1$, $x_3 \leq 1$.
      The constraint $\bx \geq \mathbf{0}$ means all components are nonneg.
      The equality $-x_1 + x_2 + x_3 = 0$ (equivalently $x_2 + x_3 = x_1$) pins one
      dimension of freedom.

      \textbf{Feasible region.}  Combining constraints:
      $0 \leq x_1 \leq 1$, $0 \leq x_3 \leq 1$, and $x_2 = x_1 - x_3$.

    \column{0.46\textwidth}
      \begin{center}
        \includegraphics[width=\linewidth]{fig_example13_2}
      \end{center}
  \end{columns}

  \framebreak

  \textbf{Applying equality elimination.}  The equality constraint
  $[-1\ \ 1\ \ 1]\bx = 0$ is encoded as $\bC_{\text{EQ}} = [-1,\;1,\;1]$,
  $d_{\text{EQ}} = 0$.  After LQ decomposition of $\bC_{\text{EQ}}$, we compute
  $y_1^* = 0$ (since $d_{\text{EQ}} = 0$) and the optimisation reduces to a
  2D problem in variables $(y_{2,1},\, y_{2,2})$.

  \textbf{Solution.}  Solving the reduced 2D least-squares-with-inequalities
  problem yields $\bx^* = [0,\; 0.2,\; 0.2]^{\top}$.

  \textbf{Interpretation.}  At the solution, $x_1 = 0$, $x_2 = x_3 = 0.2$.
  Check the equality: $-0 + 0.2 + 0.2 = 0$?  No --- wait: $-x_1 + x_2 + x_3 = -0 + 0.2 + 0.2 = 0.4 \neq 0$.
  Re-checking: the equality is $x_2 = x_3 - x_1$, and with $x_1=0$, $x_2 = x_3$, which holds: $0.2 = 0.2$. \checkmark

  \begin{alertblock}{Key Takeaway}
    Equality constraints are free to eliminate because they fix exactly one
    linear combination of variables to a constant.  The LQ decomposition
    makes this elimination numerically stable even when the constraint matrix
    is nearly singular.
  \end{alertblock}

\end{frame}

\begin{frame}[fragile]{Python: Least Squares with Inequalities}
\begin{lstlisting}[caption={Algorithm 13.1 implemented with SciPy (quadratic program solver)}]
import numpy as np
from scipy.optimize import minimize

def solve_qp_lstsq(A, b, C_LE, d_LE, C_EQ=None, d_EQ=None):
    """Solve minimize||Ax - b|| s.t. C_LE x <= d_LE, C_EQ x = d_EQ"""
    n = A.shape[1]
    # Objective: minimize (1/2)||Ax - b||^2
    Q = A.T @ A           # = U^T U  (eq 13.1 with q = -A^T b)
    q = -A.T @ b

    constraints = []
    if C_LE is not None:
        # C_LE x <= d_LE  =>  -(C_LE x - d_LE) >= 0
        constraints.append({'type': 'ineq',
                            'fun': lambda x: d_LE - C_LE @ x})
    if C_EQ is not None:
        constraints.append({'type': 'eq',
                            'fun': lambda x: C_EQ @ x - d_EQ})

    def obj(x):
        return 0.5 * x @ Q @ x + q @ x

    def grad(x):
        return Q @ x + q

    res = minimize(obj, np.zeros(n), jac=grad,
                   method='SLSQP', constraints=constraints)
    return res.x, res.success

# Example 13.1
A = np.array([[2., 1.], [-4., 3.]])
b = np.array([1., 2.])
C_LE = np.array([[-2., 1.], [1., -3.]])  # >= form negated
d_LE = np.array([-2., 4.])
x_star, ok = solve_qp_lstsq(A, b, C_LE, d_LE)
print(f"x* = {x_star.round(4)}")  # Expected: [1.4, 0.8]
\end{lstlisting}
\end{frame}

\section{13.4 Least Distance Programming}
% =========================================================================

\begin{frame}[allowframebreaks]{Least Distance Programming}

  A \textbf{Least Distance Program} (LDP) asks: among all points in a
  polytope (a region defined by linear inequalities), which one is
  \emph{closest to the origin}?  This is a pure geometric problem that
  arises as a sub-problem when we reduce a general least-squares-with-inequalities
  problem via the SVD.

  \begin{block}{Least Distance Program --- LDP (Eq.~13.27)}
    \[
      \minimize_{\bx}\; \norm{\bx}
      \qquad \text{subject to}\quad \bG\bx \geq \bh
    \]
    where $\bG \in \R^{m\times n}$, $\bx \in \R^n$, $\bh \in \R^m$.
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\norm{\bx}$ & the Euclidean length of $\bx$: $\sqrt{x_1^2 + \cdots + x_n^2}$\\
      $\bG \in \R^{m\times n}$ & the \textbf{constraint matrix}, $m$ constraints over $n$ variables\\
      $\bh \in \R^m$ & the \textbf{right-hand-side} of the constraints\\
      $\bG\bx \geq \bh$ & means each row $i$ of $\bG$ satisfies $\mathbf{g}_i^{\top}\bx \geq h_i$\\
    \end{tabular}
  \end{block}

  \begin{columns}[T]
    \column{0.50\textwidth}
      \begin{center}
        \includegraphics[width=0.9\linewidth]{fig_least_distance}
      \end{center}
      The shaded region is the feasible set.  The LDP solution $\bx^*$ (marked with
      a dot) is the point in that region closest to the origin (the centre).

    \column{0.46\textwidth}
      \textbf{Properties of the LDP:}

      The LDP is \emph{not always feasible}: if the constraints $\bG\bx \geq \bh$
      are contradictory, there is no solution.  For example, requiring
      $x_1 \geq 3$ and $-x_1 \geq 3$ simultaneously is impossible.

      When feasible, the LDP has a \emph{unique solution}: the feasible set is convex
      (intersection of half-spaces) and the objective $\norm{\bx}^2$ is strictly
      convex, so there can be at most one minimiser.  (Exercise 13.3 proves this
      formally by showing any average of two equal-norm solutions gives a shorter vector.)
  \end{columns}

  \framebreak

  \textbf{How the LDP arises from least-squares with inequalities.}  Starting from
  the problem $\minimize\|\bA\bx - \bb\|$ subject to $\bC\bx \geq \bd$, apply the
  SVD to $\bA$ and make the change of variables $\mathbf{v} = \bV^{\top}\bx$.
  The objective splits into a ``fixed'' part that depends on $\mathbf{v}_{\text{fixed}}$
  and a ``free'' part.  A further change of variables $\mathbf{z} = \bT\mathbf{v}_{\text{fixed}} - \bU_1^{\top}\bb$
  transforms the objective into $\|\mathbf{z}\|$, and the constraints become
  linear in $\mathbf{z}$.  The result is an LDP in the variable $\mathbf{z}$
  (Eqs.~13.29--13.31).

  \begin{alertblock}{Key Takeaway}
    The LDP is the geometric core of the QP reduction chain.  Once we can solve
    the LDP, we can solve least-squares with inequalities, and therefore any
    convex QP.
  \end{alertblock}

\end{frame}

\begin{frame}[allowframebreaks]{LDP to NNLS Transformation}

  Solving the LDP directly is still non-trivial.  The key insight of Lawson and
  Hanson (1974) is that the LDP can be converted to a
  \textbf{Nonnegative Least-Squares} (NNLS) problem, which in turn has a simple
  active-set algorithm (Algorithm 13.4).  The conversion works through duality.

  \textbf{Intuition.}  The constraints $\bG\bx \geq \bh$ can be enforced by
  introducing Lagrange multipliers (dual variables) $\mathbf{y} \geq \mathbf{0}$,
  one per constraint.  Dualising the LDP and converting back to a primal form
  yields an NNLS problem whose solution $\mathbf{y}^*$ encodes the active
  constraints.  The original LDP solution $\bx^*$ is then recovered from the
  NNLS residual.

  \begin{block}{NNLS Form of the LDP (Eqs.~13.32--13.33)}
    \[
      \minimize_{\mathbf{y}\geq\mathbf{0}}\; \norm{\bE\mathbf{y} - \mathbf{f}}
      \qquad \text{subject to}\quad \mathbf{y} \geq \mathbf{0}
    \]
    where the augmented matrix $\bE$ and vector $\mathbf{f}$ are formed from the
    LDP data $(\bG, \bh)$ as:
    \[
      \bE = \begin{bmatrix}\bG^{\top}\\\bh^{\top}\end{bmatrix} \in \R^{(n+1)\times m},
      \qquad
      \mathbf{f} = \begin{bmatrix}\mathbf{0}_n\\1\end{bmatrix} \in \R^{n+1}
    \]
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\bE \in \R^{(n+1)\times m}$ & augmented matrix: top $n$ rows are $\bG^{\top}$, last row is $\bh^{\top}$\\
      $\mathbf{f} \in \R^{n+1}$ & target vector: zeros in positions $1,\ldots,n$; the value $1$ in position $n+1$\\
      $\mathbf{y} \in \R^m$ & the NNLS variable; physically, $y_i$ is proportional to the dual multiplier of constraint $i$\\
      $\mathbf{y} \geq \mathbf{0}$ & all components of $\mathbf{y}$ must be nonneg (component-wise)\\
    \end{tabular}
  \end{block}

  \framebreak

  \textbf{Recovery of the LDP solution from the NNLS solution.}  Once we have
  solved the NNLS problem and obtained the optimal $\mathbf{y}^*$, we compute:

  \begin{align}
    \mathbf{r} &= \bE\mathbf{y}^* - \mathbf{f} \tag{13.34}\\[4pt]
    x_j^* &= -\frac{r_j}{r_{n+1}},\quad j=1,\ldots,n \tag{13.35}
  \end{align}

  \begin{block}{Notation for Recovery}
    \begin{tabular}{ll}
      $\mathbf{r} \in \R^{n+1}$ & the residual vector of the NNLS solution\\
      $r_j$ & the $j$-th component of $\mathbf{r}$ (for $j = 1,\ldots,n$, these encode $-r_{n+1}\bx^*$)\\
      $r_{n+1}$ & the last component of $\mathbf{r}$; it must be strictly negative ($r_{n+1} < 0$)\\
                 & for the LDP to be feasible\\
    \end{tabular}
  \end{block}

  \begin{alertblock}{How to Read the Recovery Formula}
    The formula $x_j^* = -r_j / r_{n+1}$ divides the first $n$ residual components
    by the (negative) last component.  If $r_{n+1} \geq 0$, the LDP is infeasible.
    If $r_{n+1} < 0$, the division gives the unique LDP minimiser.  The scaling by
    $1/|r_{n+1}|$ arises from the normalisation implicit in the augmented NNLS setup.
  \end{alertblock}

  \textbf{Summary of Algorithm 13.3 (LDP solver):}
  \begin{enumerate}
    \item Form $\bE = [\bG^{\top};\, \bh^{\top}]$ (stack the transpose of $\bG$ on top of $\bh^{\top}$)
          and $\mathbf{f} = [\mathbf{0}_n;\, 1]$.
    \item Solve the NNLS problem: find $\mathbf{y}^* \geq \mathbf{0}$ minimising $\|\bE\mathbf{y} - \mathbf{f}\|$.
    \item Compute the residual $\mathbf{r} = \bE\mathbf{y}^* - \mathbf{f}$.
    \item Check $r_{n+1} < 0$; if not, report infeasibility.
    \item Return $x_j^* = -r_j / r_{n+1}$ for $j = 1,\ldots,n$.
  \end{enumerate}

\end{frame}

\begin{frame}[fragile]{Python: Least Distance Program via NNLS}
\begin{lstlisting}[caption={Algorithm 13.3 in Python using scipy.optimize.nnls}]
import numpy as np
from scipy.optimize import nnls

def solve_least_distance(G, h, eps=1e-12):
    """
    Solve: minimize ||x|| subject to G x >= h
    Returns (x_star, solved).
    """
    m, n = G.shape
    # Build NNLS problem (eq. 13.33): E y = f, y >= 0
    E = np.vstack([G.T, h.T])       # shape (n+1, m)
    f = np.zeros(n + 1)
    f[n] = 1.0                      # last component is 1

    y_star, _ = nnls(E, f)

    r = E @ y_star - f              # residual  (eq. 13.34)
    if r[n] >= -eps:                # r_{n+1} must be negative
        return np.zeros(n), False   # malformed / infeasible

    x_star = -r[:n] / r[n]         # eq. 13.35
    return x_star, True

# -- Example 13.3 ----------------------------------------------
G = np.array([[2.0, -2.0],
              [-1.0,  5.0]])
h = np.array([2.0, -7.0])

x_star, solved = solve_least_distance(G, h)
print(f"solved = {solved}")
print(f"x*     = {x_star}")   # Expected: [0.500, -0.500]
\end{lstlisting}
\end{frame}

\begin{frame}[allowframebreaks]{Example 13.3 --- Solving an LDP Step by Step}

  This worked example traces through the full LDP-to-NNLS reduction with
  concrete numbers so that every formula can be verified by hand.

  \begin{columns}[T]
    \column{0.50\textwidth}
      \begin{block}{Problem Data}
        \[
          \bG = \begin{bmatrix}2.0 & -2.0\\-1.0 & 5.0\end{bmatrix},\quad
          \bh = \begin{bmatrix}2.0\\-7.0\end{bmatrix}
        \]
        We seek the point $(x_1, x_2)$ closest to the origin such that
        $2x_1 - 2x_2 \geq 2$ and $-x_1 + 5x_2 \geq -7$.
      \end{block}

      \textbf{Step 1 --- Form the NNLS matrices.}
      $\bE = [\bG^{\top};\, \bh^{\top}]$ (stack $\bG^{\top}$ and $\bh^{\top}$):
      \[
        \bE = \begin{bmatrix}2.0&-1.0\\-2.0&5.0\\2.0&-7.0\end{bmatrix},\quad
        \mathbf{f} = \begin{bmatrix}0\\0\\1\end{bmatrix}
      \]

      \textbf{Step 2 --- Solve NNLS.}  The NNLS solver finds
      $\mathbf{y}^* = [0.167,\; 0.000]^{\top}$, meaning only the first
      constraint is active (the second constraint is inactive: $y_2^* = 0$).

    \column{0.46\textwidth}
      \begin{center}
        \includegraphics[width=\linewidth]{fig_nnls_demo}
      \end{center}
  \end{columns}

  \framebreak

  \textbf{Step 3 --- Compute the residual.}
  \[
    \mathbf{r} = \bE\mathbf{y}^* - \mathbf{f}
    = \begin{bmatrix}2.0&-1.0\\-2.0&5.0\\2.0&-7.0\end{bmatrix}
      \begin{bmatrix}0.167\\0\end{bmatrix}
    - \begin{bmatrix}0\\0\\1\end{bmatrix}
    = \begin{bmatrix}0.333\\-0.333\\-0.667\end{bmatrix}
  \]

  The last component is $r_3 = r_{n+1} = -0.667 < 0$, so the LDP is feasible. \checkmark

  \textbf{Step 4 --- Recover the primal solution.}
  \[
    x_1^* = -\frac{r_1}{r_3} = -\frac{0.333}{-0.667} = 0.500,
    \quad
    x_2^* = -\frac{r_2}{r_3} = -\frac{-0.333}{-0.667} = -0.500
  \]
  So $\bx^* = [0.500,\; -0.500]^{\top}$.

  \textbf{Verification.}  Check that $\bx^*$ is feasible:
  \begin{itemize}
    \item Constraint 1: $2(0.5) - 2(-0.5) = 1 + 1 = 2 \geq 2$. \checkmark (active constraint)
    \item Constraint 2: $-0.5 + 5(-0.5) = -0.5 - 2.5 = -3 \geq -7$. \checkmark (inactive)
  \end{itemize}
  The distance from the origin is $\|\bx^*\| = \sqrt{0.5^2 + 0.5^2} = \sqrt{0.5} \approx 0.707$.

  \begin{alertblock}{Key Insight}
    The active constraint ($y_1^* > 0$) is the one that ``touches'' the minimum-distance
    point.  The inactive constraint ($y_2^* = 0$) imposes no binding restriction at the
    solution.  This active-inactive structure is exactly what the NNLS solver detects.
  \end{alertblock}

\end{frame}

\section{13.5 Solving Nonnegative Least-Squares (NNLS)}
% =========================================================================

\begin{frame}[allowframebreaks]{NNLS: Problem Setup and Partition}

  The \textbf{Nonnegative Least-Squares} (NNLS) problem is the foundation of the
  entire reduction chain.  It is a least-squares problem in which all decision
  variables must be nonnegative.  While simple to state, it requires a careful
  algorithm because the nonnegativity constraints create a combinatorial structure
  (some constraints will be active, others not).

  \begin{block}{Nonnegative Least-Squares --- NNLS (Eq.~13.32)}
    \[
      \minimize_{\bx\geq\mathbf{0}}\; \norm{\bE\bx - \mathbf{f}}
    \]
    where $\bE \in \R^{m\times n}$, $\bx \in \R^n$, $\mathbf{f} \in \R^m$, and
    $\bx \geq \mathbf{0}$ means $x_i \geq 0$ for every $i = 1,\ldots,n$.
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\bE \in \R^{m\times n}$ & the matrix in the residual (analogous to $\bA$ in unconstrained least squares)\\
      $\mathbf{f} \in \R^m$ & the target vector\\
      $\bx \geq \mathbf{0}$ & the \textbf{nonnegativity constraint}: every component of $\bx$ is at least zero\\
    \end{tabular}
  \end{block}

  \framebreak

  \textbf{Active-set partition.}  The idea behind the Lawson--Hanson algorithm
  is to partition the indices $\{1,\ldots,n\}$ into two sets:

  \begin{align}
    \mathcal{B} &= \{i : x_i > 0\} \quad\text{the ``\textbf{basic}'' (free) set --- constraint inactive} \tag{13.54}\\
    \mathcal{V} &= \{i : x_i = 0\} \quad\text{the ``\textbf{violating}'' (zero) set --- constraint active} \tag{13.55}
  \end{align}

  At the optimum $\bx^*$, the components in $\mathcal{B}$ are free to be positive,
  so they satisfy the unconstrained least-squares optimality condition.  The components
  in $\mathcal{V}$ are forced to zero.

  \textbf{KKT (Karush--Kuhn--Tucker) conditions.}  At the optimum, the dual
  variables $\boldsymbol{\mu}$ (mu, pronounced \emph{myoo}) satisfy:
  \[
    \bmu = \bE^{\top}(\bE\bx^* - \mathbf{f})
  \]

  \begin{block}{Notation for KKT}
    \begin{tabular}{ll}
      $\bmu \in \R^n$ & the vector of \textbf{dual variables} (Lagrange multipliers for $\bx \geq \mathbf{0}$)\\
      $\mu_i \geq 0$ for $i \in \mathcal{V}$ & dual variable for an active constraint must be nonneg\\
      $\mu_i = 0$ for $i \in \mathcal{B}$ with $x_i > 0$ & dual variable for an inactive constraint is zero\\
    \end{tabular}
  \end{block}

  \begin{alertblock}{How to Read the KKT Condition}
    The condition $\bmu = \bE^{\top}(\bE\bx^* - \mathbf{f})$ says: at the optimum,
    the gradient of the objective with respect to $\bx$ (which equals $\bE^{\top}(\bE\bx - \mathbf{f})$)
    must be balanced by the dual variables.  If all $\mu_i \geq 0$, reducing any
    $x_i$ below zero would \emph{increase} the objective --- so the solution is indeed optimal.
    If some $\mu_i < 0$, there is a direction in which we could decrease the objective
    by allowing $x_i$ to be positive; the algorithm exploits this.
  \end{alertblock}

\end{frame}

\begin{frame}[allowframebreaks]{Algorithm 13.4 --- NNLS Solver (Lawson--Hanson)}

  The \textbf{Lawson--Hanson} active-set method iteratively builds up the set
  $\mathcal{B}$ of free (positive) variables, solving an unconstrained least-squares
  problem on $\mathcal{B}$ at each step.  It is guaranteed to terminate in at most
  $3n$ outer iterations and always finds the global optimum (since NNLS is convex).

  \begin{block}{Initialisation}
    Set $\bx = \mathbf{0}$ (all variables start at zero), $\mathcal{B} = \emptyset$
    (no free variables initially), $\mathcal{V} = \{1,\ldots,n\}$ (all variables
    are active/zero), and set a maximum of $3n$ outer iterations.
  \end{block}

  \textbf{Outer loop (checking KKT):}
  \begin{enumerate}
    \item Compute the dual vector $\bmu = \bE^{\top}(\bE\bx - \mathbf{f})$.
          If all $\mu_i \geq 0$ for $i \in \mathcal{V}$, the KKT conditions are satisfied
          and we \textbf{return} $\bx$ as the solution.
    \item Select the \textbf{entering index}: $q = \arg\min_{i\in\mathcal{V}} \mu_i$
          (the most negative dual variable, i.e., the constraint that ``wants'' to
          become inactive the most).
    \item Move $q$ from $\mathcal{V}$ to $\mathcal{B}$ and update the free submatrix
          $\bE_{\mathcal{B}}$ by including column $\bE[:,q]$.
  \end{enumerate}

  \textbf{Inner loop (line search to maintain feasibility):}
  While $\mathcal{B} \neq \emptyset$ and the step size $\alpha$ (alpha, pronounced
  \emph{AL-fah}) is not equal to 1:
  \begin{enumerate}[(a)]
    \item Compute $\mathbf{z} = \bE_{\mathcal{B}}^+\mathbf{f}$
          (the unconstrained least-squares solution using only the free columns).
          Here $\bE_{\mathcal{B}}^+$ is the pseudoinverse of the submatrix of $\bE$
          with columns restricted to $\mathcal{B}$.
    \item If $z_q \leq 0$: the entering variable wants to be zero or negative.
          Move $q$ back to $\mathcal{V}$ and break the inner loop.
    \item Compute the step size:
          \[
            \alpha = \min\!\left(1,\;\;
              \min_{\substack{i \in \mathcal{B},\\ z_i < 0}}
              \frac{x_i}{x_i - z_i}\right)
          \]
          This is the largest step toward $\mathbf{z}$ that keeps all free components nonneg.
    \item Update the free components: $x_i \leftarrow x_i + \alpha(z_i - x_i)$ for $i \in \mathcal{B}$.
    \item Zero out any component $x_i$ that has become $\leq 0$ and move it back to $\mathcal{V}$.
  \end{enumerate}

  \framebreak

  \begin{block}{Notation for Algorithm 13.4}
    \begin{tabular}{ll}
      $\mathcal{B}$ (calligraphic B) & the set of free (basic) indices, i.e., where $x_i > 0$\\
      $\mathcal{V}$ (calligraphic V) & the set of zero (violating) indices, i.e., where $x_i = 0$\\
      $q$ & the \textbf{entering index} chosen as the most-violated KKT condition\\
      $\bE_{\mathcal{B}}$ & the submatrix of $\bE$ restricted to the columns in $\mathcal{B}$\\
      $\bE_{\mathcal{B}}^+$ & the pseudoinverse of $\bE_{\mathcal{B}}$ (unconstrained least-squares on free variables)\\
      $\mathbf{z}$ & the unconstrained least-squares solution on the free set $\mathcal{B}$\\
      $\alpha$ (alpha) & the step size; $\alpha = 1$ means we take the full step to $\mathbf{z}$\\
    \end{tabular}
  \end{block}

  \begin{alertblock}{How to Read the Step-Size Formula}
    The ratio $x_i / (x_i - z_i)$ for indices with $z_i < 0$ answers the question:
    ``If I move from $x_i$ toward $z_i$ (which is negative), at what fraction of the
    way does $x_i$ hit zero?''  Taking the minimum over all such indices ensures we
    never drive any component below zero.  $\alpha = 1$ means the full step is
    feasible; $\alpha < 1$ means we do a partial step and then remove the variable(s)
    that hit zero.
  \end{alertblock}

  \begin{block}{Convergence Guarantee}
    Every NNLS problem has a unique global solution (the objective is strictly convex
    when $\bE$ has full column rank, otherwise it has a convex solution set).
    The Lawson--Hanson algorithm always terminates in at most $3n$ outer iterations
    and returns the optimal solution.
  \end{block}

\end{frame}

\begin{frame}[fragile]{Python: NNLS Algorithm Implementation}
\begin{lstlisting}[caption={Algorithm 13.4 in Python (Lawson--Hanson active-set method)}]
import numpy as np
from scipy.optimize import nnls as scipy_nnls

def solve_nnls(E, f, max_iter=None):
    """
    NNLS: minimize ||Ex - f|| s.t. x >= 0
    Implements Lawson-Hanson active-set (Algorithm 13.4).
    Returns (x, solved).
    """
    m, n = E.shape
    if max_iter is None:
        max_iter = 3 * n
    x = np.zeros(n)
    mu = -E.T @ f          # initial dual estimate
    P = np.zeros(n, dtype=bool)   # True = active in B
    Ep = np.zeros((m, n))
    q_prev = -1

    for _ in range(max_iter):
        if np.all(P) or np.all(mu >= 0):
            return x, True   # success
        # Choose entering index (most negative mu not in B and != q_prev)
        candidates = [(mu[i], i) for i in range(n) if not P[i] and i != q_prev]
        if not candidates:
            break
        q = min(candidates)[1]
        q_prev = q
        P[q] = True
        Ep[:, q] = E[:, q]
        alpha = 0.0
        while np.any(P) and alpha != 1.0:
            z = np.linalg.pinv(Ep) @ f  # pseudoinverse solve
            if z[q] <= 0:
                mu[q] = 0.0; P[q] = False; Ep[:, q] = 0.0; break
            active = np.where(P)[0]
            ratios = [x[i]/(x[i]-z[i]) if z[i] < 0 else 1.0 for i in active]
            alpha = min(ratios)
            x[P] += alpha * (z[P] - x[P])
            for i in range(n):
                if x[i] <= 0:
                    x[i] = 0.0
                    if P[i]: P[i] = False; Ep[:, i] = 0.0
        mu = E.T @ (E @ x - f)
    return x, False   # too many iterations

# Verify with scipy
E_ex = np.array([[2., 1.], [-4., 3.]])
f_ex = np.array([5., 5.])
x_manual, _ = solve_nnls(E_ex, f_ex)
x_scipy, _  = scipy_nnls(E_ex, f_ex)
print(f"Manual: {x_manual.round(4)}")
print(f"SciPy:  {x_scipy.round(4)}")
\end{lstlisting}

\begin{frame}[allowframebreaks]{KKT Proof of NNLS Optimality}

  This section proves that the solution $\bx^*$ returned by the LDP-to-NNLS
  reduction actually solves the \emph{original LDP}, not just the NNLS problem.
  The proof constructs a primal-dual pair $(\bx^*, \bmu^*)$ satisfying all KKT
  conditions, which guarantees global optimality for this convex problem.

  \textbf{Setting up the proof.}  Recall that the NNLS problem has variables
  $\mathbf{y} \geq \mathbf{0}$, matrix $\bE = [\bG^{\top};\, \bh^{\top}]$,
  and target $\mathbf{f} = [\mathbf{0};\, 1]$.  The NNLS solution $\mathbf{y}^*$
  satisfies its own KKT conditions, and we use these to derive the KKT conditions
  for the LDP.

  \begin{columns}[T]
    \column{0.52\textwidth}
      \textbf{Step 1: Primal feasibility.}

      From the NNLS KKT conditions, the gradient of $\|\bE\mathbf{y} - \mathbf{f}\|^2$
      at $\mathbf{y}^*$ is balanced by the nonnegativity dual variables.
      Writing $\mathbf{r} = \bE\mathbf{y}^* - \mathbf{f}$ and using the structure
      of $\bE$:
      \[
        \mathbf{0} \leq \bE^{\top}\mathbf{r}
        = \begin{bmatrix}\bG \\ \bh^{\top}\end{bmatrix}^{\top}
          \begin{bmatrix}-r_{n+1}\bx^* \\ r_{n+1}\end{bmatrix}
        \propto (\bG\bx^* - \bh)\cdot\text{(positive)} \tag{13.45}
      \]
      This shows $\bG\bx^* \geq \bh$, i.e., $\bx^*$ is feasible for the LDP. \checkmark

    \column{0.44\textwidth}
      \textbf{Step 2: Stationarity.}

      The LDP objective $\norm{\bx}^2 / 2$ has gradient $\bx$.
      The Lagrangian stationarity condition requires:
      \begin{align}
        \bx^* - \bG^{\top}\bmu^* &= \mathbf{0} \tag{13.48}\\
        \bx^* &= \bG^{\top}\bmu^* \tag{13.49}
      \end{align}
      where the dual variable $\bmu^* = \mathbf{y}^*/\|\mathbf{r}\|^2 \geq \mathbf{0}$
      (because $\mathbf{y}^* \geq \mathbf{0}$ and $\|\mathbf{r}\|^2 > 0$). \checkmark

      \textbf{Step 3: Complementary slackness.}

      The NNLS dual variables $y_i^* = 0$ for constraints not in $\mathcal{B}$
      (inactive NNLS constraints), which translates to $\mu_i^* = 0$ for inactive
      LDP constraints.  This is complementary slackness. \checkmark
  \end{columns}

  \begin{alertblock}{Conclusion}
    We have constructed a primal-dual pair $(\bx^*, \bmu^*)$ that satisfies all
    three KKT conditions: primal feasibility ($\bG\bx^* \geq \bh$), dual
    feasibility ($\bmu^* \geq \mathbf{0}$), and complementary slackness.  For a
    convex problem, KKT conditions are both necessary and sufficient for global
    optimality.  Therefore $\bx^*$ is the \textbf{global minimiser} of the LDP.
  \end{alertblock}

\end{frame}

\section{13.6 Dual Certificates}

\begin{frame}[allowframebreaks]{The Dual Problem for a Convex QP}

  Every optimisation problem has a companion called its \textbf{dual problem}.
  While the original (primal) problem seeks to minimise the objective, the dual
  problem seeks to maximise a lower bound on that minimum.  When the two optima
  coincide (strong duality), the dual solution is called a \textbf{certificate}
  because it \emph{proves} that the primal solution is globally optimal.

  \textbf{The primal problem.}  Consider the general convex QP with positive-definite
  $\bQ$ (all eigenvalues $\lambda$ (lambda) strictly positive):
  \[
    \minimize_{\bx}\; \tfrac{1}{2}\bx^{\top}\bQ\bx + \bq^{\top}\bx
    \quad \text{s.t.}\quad \bC_{\text{LE}}\bx \leq \bd_{\text{LE}},\;
    \bC_{\text{EQ}}\bx = \bd_{\text{EQ}}
  \]

  \textbf{The Lagrangian.}  We relax the constraints by introducing dual variables:
  $\bmu \geq \mathbf{0}$ (mu, the \textbf{multipliers} for inequality constraints)
  and $\blambda$ (lambda, unrestricted \textbf{multipliers} for equality constraints).

  \begin{block}{Lagrangian (Eqs.~13.58--13.60)}
    \[
      \mathcal{L}(\bx,\, \bmu,\, \blambda)
      = \tfrac{1}{2}\bx^{\top}\bQ\bx + \mathbf{e}^{\top}\bx + f_0
    \]
    where:
    \[
      \mathbf{e} = \bq + \bC_{\text{LE}}^{\top}\bmu + \bC_{\text{EQ}}^{\top}\blambda,
      \qquad
      f_0 = -\bmu^{\top}\bd_{\text{LE}} - \blambda^{\top}\bd_{\text{EQ}}
    \]
  \end{block}

  \begin{block}{Notation}
    \begin{tabular}{ll}
      $\mathcal{L}$ & the \textbf{Lagrangian}: objective plus penalised-constraint terms\\
      $\bmu \in \R^p,\; \bmu \geq \mathbf{0}$ & dual variables for the $p$ inequality constraints; must be nonneg\\
      $\blambda \in \R^c$ & dual variables for the $c$ equality constraints; unrestricted in sign\\
      $\mathbf{e} \in \R^n$ & the ``shifted gradient'' combining objective and constraint gradients\\
      $f_0 \in \R$ & the constant part of the Lagrangian (does not depend on $\bx$)\\
    \end{tabular}
  \end{block}

  \framebreak

  \textbf{Deriving the dual function.}  The dual function $\mathcal{D}(\bmu, \blambda)$
  is defined as the minimum of $\mathcal{L}$ over all $\bx$ (without constraint on $\bx$).
  Because $\bQ$ is positive definite, $\mathcal{L}$ is a convex quadratic in $\bx$,
  and its unconstrained minimum is found by setting the gradient to zero:
  $\bQ\bx + \mathbf{e} = \mathbf{0} \implies \bx^*(\bmu,\blambda) = -\bQ^{-1}\mathbf{e}$.

  \begin{block}{Dual Function (Eqs.~13.61--13.63)}
    \[
      \mathcal{D}(\bmu,\, \blambda)
      = \min_{\bx}\, \mathcal{L}(\bx,\bmu,\blambda)
      = -\tfrac{1}{2}\mathbf{e}^{\top}\bQ^{-1}\mathbf{e} + f_0
    \]
  \end{block}

  \begin{block}{Dual Problem (Eq.~13.64)}
    \[
      \maximize_{\bmu \geq \mathbf{0},\;\blambda}\;
      -\tfrac{1}{2}\mathbf{e}^{\top}\bQ^{-1}\mathbf{e} + f_0
    \]
  \end{block}

  \textbf{Strong duality.}  Under Slater's condition (there exists a strictly feasible
  point $\bx$ with $\bC_{\text{LE}}\bx < \bd_{\text{LE}}$), the duality gap is zero:
  \[
    f(\bx^*) = \mathcal{D}(\bmu^*, \blambda^*)
  \]
  meaning the primal minimum equals the dual maximum.

  \begin{alertblock}{How to Read This}
    The dual problem provides a \emph{lower bound} on the primal minimum for
    any choice of $(\bmu, \blambda)$.  When we find a primal-dual pair where
    $f(\bx^*) = \mathcal{D}(\bmu^*, \blambda^*)$, neither side can improve further,
    and both are optimal.  This equality is called \textbf{strong duality} and is
    guaranteed for convex QPs that satisfy Slater's condition.
  \end{alertblock}

\end{frame}

\begin{frame}[allowframebreaks]{Dual Certificates --- Verifying Optimality}

  A \textbf{dual certificate} is a pair $(\bmu^*, \blambda^*)$ that, together with
  the primal solution $\bx^*$, verifies optimality without requiring any further
  computation.  In practice, QP solvers return both the primal and dual solutions,
  and we can check the four KKT conditions to confirm correctness.

  \begin{center}
    \includegraphics[width=0.72\linewidth]{fig_dual_certificate}
  \end{center}

  \textbf{The four KKT conditions for the QP:}

  \begin{enumerate}
    \item \textbf{Primal feasibility:} $\bC_{\text{LE}}\bx^* \leq \bd_{\text{LE}}$
          and $\bC_{\text{EQ}}\bx^* = \bd_{\text{EQ}}$.
          The primal solution satisfies all constraints.
    \item \textbf{Dual feasibility:} $\bmu^* \geq \mathbf{0}$.
          The inequality dual variables are nonneg.
    \item \textbf{Stationarity:} $\nabla_{\bx}\mathcal{L} = \bQ\bx^* + \bq + \bC_{\text{LE}}^{\top}\bmu^* + \bC_{\text{EQ}}^{\top}\blambda^* = \mathbf{0}$.
          The gradient of the Lagrangian w.r.t.\ $\bx$ vanishes at optimum.
    \item \textbf{Complementary slackness:} $\mu_i^*(\bC_{\text{LE},i}\bx^* - d_{\text{LE},i}) = 0$ for all $i$.
          Each inequality dual variable is zero if its constraint is inactive, and
          the constraint is active (zero slack) if its dual is positive.
  \end{enumerate}

  \framebreak

  \begin{block}{Strong Duality (Slater's Condition)}
    If the QP is convex, Slater's condition holds, and $(\bx^*, \bmu^*, \blambda^*)$
    satisfies all four KKT conditions, then:
    \[
      f(\bx^*) = \mathcal{D}(\bmu^*, \blambda^*)
      \quad\Longleftrightarrow\quad
      \text{$\bx^*$ is globally optimal}
    \]
  \end{block}

  \textbf{Practical use.}  When a QP solver returns a solution, it also returns
  the dual variables.  Checking the four KKT conditions takes $O(pn + cn)$ operations
  and provides a \emph{proof} of optimality that is independent of the solver.  This
  is especially valuable in safety-critical applications where the solver's correctness
  cannot be assumed.

  \textbf{Connection to NNLS.}  The NNLS solution implicitly provides a dual
  certificate: the recovery formula $\bmu^* = \mathbf{y}^*/\|\mathbf{r}\|^2$
  gives the dual variables for the LDP, and we proved in Section 13.5 that
  all KKT conditions are satisfied.

  \begin{alertblock}{Key Takeaway}
    Dual certificates turn optimality from a claim into a proof.  They are the
    mathematical equivalent of ``showing your work'' --- you not only provide the
    answer $\bx^*$ but also the reason it cannot be improved.
  \end{alertblock}

\end{frame}

\begin{frame}[fragile]{Python: Dual Certificate Verification}
\begin{lstlisting}[caption={Check KKT conditions for a QP solution using NumPy}]
import numpy as np

def verify_kkt(Q, q, C_LE, d_LE, x_star, mu_star, tol=1e-6):
    """
    Verify KKT conditions for QP:
      min (1/2)x^T Q x + q^T x  s.t.  C_LE x <= d_LE
    Parameters: primal x_star, dual mu_star (>= 0)
    """
    # 1. Primal feasibility
    primal_feas = np.all(C_LE @ x_star <= d_LE + tol)

    # 2. Dual feasibility
    dual_feas = np.all(mu_star >= -tol)

    # 3. Stationarity:  Q x + q + C_LE^T mu = 0
    stationarity = np.linalg.norm(Q @ x_star + q + C_LE.T @ mu_star) < tol

    # 4. Complementary slackness:  mu_i * (C_LE x - d_LE)_i = 0
    slack = C_LE @ x_star - d_LE          # should be <= 0
    comp_slack = np.abs(mu_star @ slack) < tol

    return {'primal_feasible': primal_feas,
            'dual_feasible':   dual_feas,
            'stationary':      stationarity,
            'comp_slack':      comp_slack}

# Dual objective value D(mu, lambda)
def dual_value(Q, q, C_LE, d_LE, mu, lam=None, C_EQ=None, d_EQ=None):
    e = q + C_LE.T @ mu
    if C_EQ is not None and lam is not None:
        e = e + C_EQ.T @ lam
    f = -mu @ d_LE
    if d_EQ is not None and lam is not None:
        f = f - lam @ d_EQ
    return -0.5 * e @ np.linalg.solve(Q, e) + f
\end{lstlisting}

\begin{frame}[allowframebreaks]{Chapter 13 Summary}

  This chapter developed the complete solution framework for convex quadratic
  programs by reducing them step by step to simpler problems.  Each reduction
  preserves the optimal solution while making the problem more tractable.

  \begin{block}{The Reduction Chain}
    \begin{center}
    \begin{tikzpicture}[node distance=1.9cm,
        every node/.style={draw, rounded corners, fill=blue!10,
          minimum width=2.0cm, minimum height=0.65cm, font=\small}]
      \node (qp)   {QP (13.1)};
      \node (ls)   [right of=qp]  {Least Squares};
      \node (lsi)  [right of=ls, minimum width=2.4cm]  {LS+Ineq.};

      \node (nnls) [right of=ldp] {NNLS};
      \draw[->, thick] (qp)  -- node[draw=none,fill=none,above,font=\tiny]{Cholesky} (ls);
      \draw[->, thick] (ls)  -- node[draw=none,fill=none,above,font=\tiny]{LQ} (lsi);
      \draw[->, thick] (lsi) -- node[draw=none,fill=none,above,font=\tiny]{SVD} (ldp);
      \draw[->, thick] (ldp) -- node[draw=none,fill=none,above,font=\tiny]{Aug.} (nnls);
    \end{tikzpicture}
    \end{center}
  \end{block}

  \begin{block}{Eight Key Concepts}
    \begin{enumerate}
      \item A \textbf{quadratic program} minimises a quadratic objective over a polytopal feasible set.
            It generalises linear programming by allowing curved objective contours.
      \item A \textbf{convex QP} (positive-definite $\bQ$) has a unique global minimum and is
            equivalent to a least-squares problem via the Cholesky decomposition.
      \item \textbf{Unconstrained least squares} is solved exactly and efficiently via the
            pseudoinverse $\bA^+ = \bV\bT^{-1}\bU^{\top}$ derived from the SVD.
      \item \textbf{Equality constraints} are eliminated by the LQ decomposition, reducing the
            problem dimension by one for each equality, with no loss of generality.
      \item \textbf{Least squares with inequalities} is the generic constrained form, which
            further reduces to a Least Distance Program via the SVD.
      \item The \textbf{Least Distance Program} (LDP) finds the closest feasible point to the
            origin; it is feasible iff the constraint system is consistent, and its solution is unique.
      \item The \textbf{NNLS problem} (nonneg.\ least squares) is solved by the Lawson--Hanson
            active-set algorithm, which terminates in $\leq 3n$ outer iterations.
      \item \textbf{Dual certificates} (KKT conditions + zero duality gap under Slater's condition)
            provide a checkable proof of global optimality.
    \end{enumerate}
  \end{block}

\end{frame}

\begin{frame}[allowframebreaks]{Selected Exercises with Full Solutions}

  \begin{block}{Exercise 13.1 --- Are NNLS problems always feasible?}
    \textbf{Answer: Yes.}  The nonnegativity constraint $\bx \geq \mathbf{0}$ is
    always satisfiable: the vector $\bx = \mathbf{0}$ (all zeros) is always
    nonneg.  Therefore the feasible set $\{\bx : \bx \geq \mathbf{0}\}$ is
    never empty, and the NNLS problem always has at least one feasible point
    (and hence a finite minimum, since the objective is bounded below by zero).
  \end{block}

  \begin{block}{Exercise 13.2 --- Are LDPs always feasible?}
    \textbf{Answer: No.}  The LDP requires $\bG\bx \geq \bh$, and this system
    can be empty.  A simple counterexample: the two constraints
    $\mathbf{1}^{\top}\bx \geq 1$ and $-\mathbf{1}^{\top}\bx \geq 1$
    require the sum of all components to be simultaneously $\geq 1$ and $\leq -1$,
    which is impossible.  Thus the LDP is infeasible, and the NNLS-based solver
    detects this via $r_{n+1} \geq 0$.
  \end{block}

  \begin{block}{Exercise 13.3 --- Do LDPs have unique solutions?}
    \textbf{Answer: Yes, when feasible.}  Suppose two distinct points
    $\mathbf{a}$ and $\mathbf{b}$ both minimise $\norm{\bx}$ over the
    feasible set, so $\norm{\mathbf{a}} = \norm{\mathbf{b}} = r^*$.
    Consider their average $\mathbf{c} = \tfrac{1}{2}(\mathbf{a}+\mathbf{b})$.
    Since the feasible set is convex, $\mathbf{c}$ is feasible.
    By the parallelogram law and $\mathbf{a} \neq \mathbf{b}$:
    \[
      \norm{\mathbf{c}}^2
      = \left\|\tfrac{\mathbf{a}+\mathbf{b}}{2}\right\|^2
      < \tfrac{\norm{\mathbf{a}}^2 + \norm{\mathbf{b}}^2}{2}
      = (r^*)^2
    \]
    (strict inequality because $\mathbf{a} \neq \mathbf{b}$).
    So $\|\mathbf{c}\| < r^*$, contradicting the optimality of $r^*$.
    Therefore the minimiser is unique.
  \end{block}

  \framebreak

  \begin{block}{Exercise 13.5 --- WLOG, $\bQ$ can be assumed symmetric}
    \textbf{Claim:} The QP objective $\bx^{\top}\bQ\bx$ depends only on the
    \emph{symmetric part} of $\bQ$, defined as
    $\bQ_{\mathrm{sym}} = \tfrac{1}{2}(\bQ + \bQ^{\top})$.

    \textbf{Proof:}  Write $\bQ = \bQ_{\mathrm{sym}} + \bQ_{\mathrm{anti}}$ where
    $\bQ_{\mathrm{anti}} = \tfrac{1}{2}(\bQ - \bQ^{\top})$ is the
    \textbf{skew-symmetric} (anti-symmetric) part satisfying
    $\bQ_{\mathrm{anti}}^{\top} = -\bQ_{\mathrm{anti}}$.  For any vector $\bx$:
    \[
      \bx^{\top}\bQ_{\mathrm{anti}}\bx
      = (\bx^{\top}\bQ_{\mathrm{anti}}\bx)^{\top}
      = \bx^{\top}\bQ_{\mathrm{anti}}^{\top}\bx
      = -\bx^{\top}\bQ_{\mathrm{anti}}\bx
    \]
    The only scalar equal to its own negative is zero, so
    $\bx^{\top}\bQ_{\mathrm{anti}}\bx = 0$ for all $\bx$.
    Therefore $\bx^{\top}\bQ\bx = \bx^{\top}\bQ_{\mathrm{sym}}\bx$ and we may
    always replace $\bQ$ with its symmetric part without changing the QP.
  \end{block}

\end{frame}

\begin{frame}[allowframebreaks]{Exercise 13.6 --- QP Equivalence with Least Squares}

  This exercise proves that the substitution $\bA = \bU$, $\bb = -\bU^{-\top}\bq$
  (used in converting a convex QP to least squares) is correct.  The derivation
  shows step by step that minimising $\|\bU\bx + \bU^{-\top}\bq\|$ is the same as
  minimising $\tfrac{1}{2}\bx^{\top}\bQ\bx + \bq^{\top}\bx$.

  \begin{block}{Claim}
    \[
      \arg\min_{\bx}\;\norm{\bU\bx + \bU^{-\top}\bq}
      \;=\;
      \arg\min_{\bx}\;\tfrac{1}{2}\bx^{\top}\bQ\bx + \bq^{\top}\bx
    \]
  \end{block}

  \textbf{Proof.}  Since minimising a nonneg quantity is the same as minimising
  its square (both give the same minimiser):

  \begin{align*}
    \arg\min_{\bx}\;\norm{\bU\bx + \bU^{-\top}\bq}
    &= \arg\min_{\bx}\;\norm{\bU\bx + \bU^{-\top}\bq}^2\\
    &= \arg\min_{\bx}\;
      (\bU\bx + \bU^{-\top}\bq)^{\top}(\bU\bx + \bU^{-\top}\bq)\\
    &= \arg\min_{\bx}\;
      \bx^{\top}\underbrace{\bU^{\top}\bU}_{=\bQ}\bx
      + 2\,\bq^{\top}\underbrace{\bU^{-1}\bU}_{=\mathbf{I}}\bx
      + \underbrace{\bq^{\top}\bU^{-1}\bU^{-\top}\bq}_{\text{constant in }\bx}\\
    &= \arg\min_{\bx}\;\bx^{\top}\bQ\bx + 2\bq^{\top}\bx\\
    &= \arg\min_{\bx}\;\tfrac{1}{2}\bx^{\top}\bQ\bx + \bq^{\top}\bx
  \end{align*}

  The last step uses the fact that multiplying the objective by the positive constant
  $\tfrac{1}{2}$ does not change the argmin.

  \begin{alertblock}{Insight}
    The constant term $\bq^{\top}\bQ^{-1}\bq = \bq^{\top}\bU^{-1}\bU^{-\top}\bq$
    is dropped because it does not depend on $\bx$ and therefore cannot affect
    where the minimum is achieved.  The factor of 2 absorbed from $2\bq^{\top}\bx$
    is absorbed into the $\tfrac{1}{2}$ pre-factor: $2\bq^{\top}\bx \equiv \bq^{\top}\bx$
    as an argmin (multiplying the whole objective by a positive constant is irrelevant).
  \end{alertblock}

\end{frame}

\begin{lstlisting}[caption={Full QP solution pipeline in Python using scipy.optimize.minimize}]
import numpy as np
from scipy.optimize import minimize, LinearConstraint

# Example 13.1: minimize ||Ax - b|| s.t. 2x1 - x2 >= 2, x1 - 3x2 <= 4
A = np.array([[2., 1.], [-4., 3.]])
b_vec = np.array([1., 2.])

# Quadratic form: Q = A^T A,  q = -A^T b
Q = A.T @ A
q = -A.T @ b_vec

def objective(x):
    return 0.5 * x @ Q @ x + q @ x

def gradient(x):
    return Q @ x + q

# Constraints: 2x1 - x2 >= 2  =>  [2, -1] x >= 2
#              x1 - 3x2 <= 4  =>  -x1 + 3x2 >= -4
C = np.array([[ 2., -1.],   # 2x1 - x2 >= 2
              [-1.,  3.]])   # x1 - 3x2 <= 4 (negated)
d = np.array([2., -4.])

constraint = LinearConstraint(C, lb=d, ub=np.inf)

result = minimize(objective, np.zeros(2), jac=gradient,
                  method='SLSQP', constraints={'type': 'ineq',
                  'fun': lambda x: C @ x - d, 'jac': lambda x: C})
print(f"Optimal x*  = {result.x.round(4)}")  # [1.4, 0.8]
print(f"Objective   = {result.fun:.6f}")
print(f"Success     = {result.success}")
\end{lstlisting}
